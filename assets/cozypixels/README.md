# CozyPixels Catppuccin wallpapers

These wallpapers come from [CozyPixels](https://github.com/SleepyCatHey/CozyPixels),
curated by [SleepyCatHey](https://github.com/SleepyCatHey), pinned to commit
`e5eec73772ee690fccbbf279cf5a2dff15887bda` on 2026-11-05.

| Source folder | Image entries |

The 38 source entries produce **36 unique wallpapers**. `pixel-napping.png`
and `pixel-reading.png` occur in two source folders and are included once per
theme. All downloaded files were checked against their upstream Git blob
hashes. [manifest.json](manifest.json) maps each wallpaper to its source paths
and records output checksums and dimensions.

The collection is included in `catppuccin`, `catppuccin-latte`,
`catppuccin-frappe`, `catppuccin-macchiato`, and `catppuccin-mocha`, with
`cozypixels-` filenames. Each flavour keeps the artwork's original colours.
The existing wallpapers remain available. Open `theme wallpaper` and search
for `cozypixels`, or use `theme browse` to choose a wallpaper with its preset.

All static images retain their original bytes. `retro2_live.gif` is represented
by its first frame as `cozypixels-retro2-live.png` so it works with the static
Sway wallpaper workflow. The original GIF is preserved in
[`originals/retro2_live.gif`](originals/retro2_live.gif); the manifest records
the conversion. Animation support is not required.

Credit belongs to SleepyCatHey as the collection curator and to the original
wallpaper artists. The upstream [MIT notice](LICENSE), including its copyright
for Sam!, is preserved. CozyPixels [explains](https://github.com/SleepyCatHey/CozyPixels/blob/e5eec73772ee690fccbbf279cf5a2dff15887bda/README.md#%EF%B8%8F-about-this-collection)
that many images were collected without tracking their original sources.
This import preserves that provenance limitation and makes no claim that
the curator or this repository created the artwork or owns every image.
